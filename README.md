## 💡 About The Project

This website is built to showcase real-world mobile applications, machine learning projects, and software architectures crafted by Zeenat Shaikh. 

### 🌟 Key Highlights

- **BliXo.Tech Brand Venture Section**: Spotlighting independent software ventures, founder responsibilities, and digital product craftsmanship.
- **SmartKhata Real Screenshot Showcase**: Interactive Android mockup featuring real app screenshots (Home Dashboard, Monthly Analytics, AI Voice Assistant, Navigation Drawer, Splash).
- **Featured Projects**: Deep showcases for *SmartKhata*, *Used Bike Price Prediction (ML)*, *Mechworkx*, *Phonics Learning App*, and *Lavish Ambiance Design*.
- **"My Journey" Timeline**: Chronological milestones tracking BCA education, native Android & Flutter development, internship team leadership at Welogical Software Solutions, and graduation in May 2026.
- **Interactive Technology Wall**: Filterable tech stack grouped by Mobile, Backend, Web, Machine Learning, Database, and Tools.
- **Dark Luxury Aesthetics**: Ultra-dark `#08090D` atmosphere, ambient aurora mesh gradients, glassmorphism panels, and smooth Framer Motion spring physics.

## 🛠️ Technology Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://framer.com/motion)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Form Management**: React Hook Form + Zod validation
- **Type System**: [TypeScript](https://www.typescriptlang.org/)

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Z-oss-tech/zeenat-portfolio.git
   cd zeenat-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the dev server**:
   ```bash
   npm run dev
   ```

4. **Open in Browser**: Navigate to `http://localhost:3000`.
